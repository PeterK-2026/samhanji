# 삼한지 三韓志

고구려·백제·신라, 그리고 당. 7세기 한반도를 배경으로 한 턴제 전략 게임입니다.
KOEI의 『삼국지 2』(1989)의 게임 구조(월 단위 턴, 지역별 숫자 명령, 장수 능력치, 공성전)를 참고해
**웹 네이티브로 새로 구현**했습니다. 원작의 코드·그래픽·데이터는 쓰지 않았습니다. 원작 분석은 [docs/01-rtk2-eng-analysis.md](docs/01-rtk2-eng-analysis.md)에 있습니다.

**플레이: https://peterk-2026.github.io/samhanji/** (`npm run deploy`: 테스트 → `/samhanji/` 경로로 빌드 → `gh-pages` 브랜치에 올림)

## 실행

```bash
npm install
npm run dev
```

- `npm run build` — 타입 검사 후 `dist/`로 빌드 (하위 경로에 올릴 때는 `BASE_PATH=/samhanji/`)
- `npm run sim -- <시나리오 1~4> <연수>` — AI끼리만 진행하는 헤드리스 시뮬레이션 (연도별 세력 현황 출력)

## 테스트와 평가

세 가지 층으로 나뉩니다. 모두 `src/dev/`의 공용 도구(시드 난수, 상태 불변식 검사, 화면 없는 실행기)를 씁니다.

```bash
npm test                      # Vitest 전체 (약 10초)
npm run test:watch            # 파일을 고칠 때마다 다시 실행
npm run eval -- 20 40         # 시나리오마다 20판 × 40년 AI 대전 → reports/eval-latest.md
npm run eval -- 5 20 3        # 시나리오 3만 5판 × 20년
```

**1. 자동 테스트 (`tests/`, Vitest)**

| 파일 | 확인하는 것 |
|---|---|
| `data.test.ts` | 인물 id·이름 중복, 능력치·생몰년 범위, 지역 인접의 대칭·연결성, 시나리오 배치·군주·후계자 id |
| `hex.test.ts` | 육각 좌표의 이웃·거리, 32개 지역 전장이 같은 시드에서 같게 나오는지, 네 방향 진입 칸에서 본성까지 길이 있는지 |
| `josa.test.ts` | 조사 자동 교정 (이/가, 을/를, (으)로, 숫자) |
| `state.test.ts` | 네 시나리오의 시작 상태가 불변식을 지키는지, 같은 시드면 같은 상태인지 |
| `game.test.ts` | AI끼리 8년 진행(시나리오×시드), 재현성, **몽키 테스트**: 플레이어 세력의 모든 선택을 무작위로 골라 3년 진행 |

불변식(`src/dev/check.ts`)은 매달 검사합니다: 장수가 자기 세력 땅에 있는지, 금·군량이 한도 안인지, 능력치·민심이 0~100인지,
살아 있는 세력에 군주와 영토가 있는지, 멸망한 세력에 땅이 남지 않았는지 등. 한 달에 IO 호출이 2만 번을 넘으면 무한 루프로 봅니다.

**2. 밸런스 평가 (`scripts/eval.ts`)**

시드 1~N으로 AI끼리 돌려 `reports/eval-latest.md`(보고서)와 `.json`(원자료)을 남깁니다. 시나리오별로 통일률·통일 세력·통일까지 걸린 햇수,
세력별 생존율·평균 최종 지역, 연간 점령 횟수, 영토 변화가 없었던 해(교착)의 비율, 오류·불변식 위반 판 수를 보여 주고,
기준선을 벗어나면 ⚠️로 표시합니다(한 세력 통일 80% 초과, 통일률 10% 미만, 교착 50% 초과 등). 오류나 위반이 있으면 종료 코드 1로 끝납니다.
같은 시드는 같은 결과를 내므로, 규칙을 바꾼 전후 보고서를 비교하면 됩니다.

**3. 브라우저 디버그 모드 (`?debug`)**

```
http://localhost:5174/?debug                                   # 디버그 패널만
http://localhost:5174/?debug&scenario=3&play=silla&seed=42     # 설정 화면을 건너뛰고 바로 시작 (시드 고정)
http://localhost:5174/?debug&scenario=1&play=&watch=1          # 관전 모드로 바로 시작
```

매개변수: `scenario`(1~4), `play`(goguryeo·baekje·silla·tang, 쉼표로 여럿, 비우면 관전), `seed`, `diff`(1~3), `mode`(history·fiction), `watch`(1이면 다른 세력 전투 보기).
왼쪽 아래 패널에서 할 수 있는 것:

- **금·군량 가득 / 병사·훈련 가득 / 재야 공개** — 특정 상황을 빨리 만들어 시험
- **자동 진행 N개월** — 플레이어 나라를 잠시 AI에게 맡겨 몇 달·몇 년 뒤 상황으로 건너뜀 (지금 명령을 마치면 시작)
- **전투 속도** — 보통·빠르게·즉시
- **불변식 검사** — 현재 상태를 `check.ts`로 검사하고 세력 현황 표시
- **상태 복사 / 붙여넣기** — 상태 JSON을 클립보드로 주고받아 버그 상황을 재현 (콘솔의 `__debug.dump()`도 같음)

**밸런스 조정 기록 (2026-10-25)** — 첫 평가에서 AI끼리 40년을 돌려도 통일이 거의 없고(0~5%) 영토 변화 없는 해가 59~76%였습니다.

## 그림 (인물 초상화·도시)

인물 160명의 초상화와 32개 지역의 도시 그림은 Codex CLI의 이미지 생성 기능으로 만들었습니다.

```bash
npm run images:manifest   # officers.ts·officers-extra.ts와 지역 설명으로 프롬프트 목록(assets-src/manifest.json) 생성
npm run images:gen        # 없는 그림만 Codex CLI로 병렬 생성 (인자: 동시 작업 수, 묶음 크기)
npm run images:optimize   # 원본 PNG → public/img/*.webp (초상화 256px, 도시 600×400)
```

- 원본 PNG(`assets-src/officers`, `assets-src/regions`)는 용량이 커서 git에서 제외했습니다. 게임은 `public/img/`의 WebP만 씁니다.
- 그림이 없는 인물·지역은 그림 없이 표시됩니다.
- 생성된 그림은 고증 자료가 아니라 게임용 상상화입니다.
- 화면에서는 지역 정보 패널의 도시 배너와 군주 초상, 장수 선택 목록의 썸네일, 장수 정보·포로 카드, 전장의 부대 초상에 쓰입니다.
- **전략 지도**(`public/img/map/strategic.webp`): `python scripts/map-reference.py`로 게임의 해안선을 기준 이미지로 그리고, 그 이미지를 Codex에 넣어 고지도풍으로 그렸습니다(`assets-src/map/prompt.txt`). 그래서 지역 좌표와 그림이 맞습니다.
- **전장 그림**(`public/img/battlefields/<지역>.webp`): 지역마다 전장 지형 배치가 고정되어 있으므로, 그 배치를 색 기준 이미지로 내보내 Codex에 넣고 32곳의 전장을 완성된 그림으로 그렸습니다. 지형·성 위치가 게임 규칙과 맞습니다.
  - 순서: `npx esbuild scripts/export-fields.ts …`로 `fields.json`을 만들고 → `python scripts/battlefield-references.py`(기준 이미지) → `python scripts/gen-battlefields.py`(Codex, 없는 것만) → `npm run images:optimize`
  - 그림이 없는 지역은 지형 질감(`public/img/battle/`)을 이어 붙인 화면으로 대신합니다.
- **부대**: 나라별 병사 무리 그림(`troop-<나라>.webp`, 투명 배경)과 장수 초상 배지, 병력 표시(원작처럼 백 단위, 총대장은 앞에 o)로 나타냅니다. 칸 테두리는 이동·대상을 고를 때만 보입니다.
- **전략 지도의 나라 표시**: 지역마다 가장 가까운 세력 색으로 영역을 옅게 칠하고(육지만), 나라 이름(高句麗·百濟·新羅·唐)과 범례(세력별 지역 수)를 겹쳐 보여 줍니다. 타이틀 화면에서는 642년 세력도를 미리 보여 줍니다.

### 명령 (0~19)

0 휴식 · 1 이동 · 2 수송 · 3 전쟁 · 4 군사(징병/재배치/훈련) · 5 인재(탐색/등용/빼내기) · 6 외교(예물/동맹/파기) ·
7 첩보(정탐/이간/유언비어) · 8 정보 · 9 개간 · 10 치수 · 11 포상 · 12 시혜 · 13 상인 · 14 세율 · 15 세력 · 16 위임 · 17 추방 · 18 조언 · 19 기타(저장/불러오기)

정보·세율·세력·위임·추방·조언·기타는 그 달의 명령 횟수를 쓰지 않습니다.

### 전투 연출

보고 있는 전투에서는 부대가 행동할 때마다 전장 위에 움직임이 그려집니다 (`BattleMap.play`, 엔진은 `IO.battleFx`로 알린다).
공격은 상대 쪽으로 몸을 던졌다 돌아오고 부딪치는 섬광·흔들림·양쪽 손실 숫자가 떠오르며, 돌격은 흙먼지와 연타, 화계는 포물선 불화살과 불길(실패하면 연기),
이간은 금빛 점선과 成/失, 일기토는 교차한 칼과 불꽃, 궤멸은 흙먼지로 보입니다. 연출이 끝나야 다음 행동으로 넘어가며,
디버그 패널의 전투 속도(빠르게·즉시)를 따릅니다. 보지 않는 AI끼리의 전투는 연출 없이 바로 계산합니다.

### 해설 카드

기록창 아래에는 Vox 해설 영상 풍의 해설 카드가 붙습니다 (`src/ui/scenes.ts`, 움직임은 `style.css`의 `.v-*`).
종이 질감 바탕에 찢어 붙인 사진, 형광펜 제목, 붉은 펜 주석을 쓰고, 지금 보고 있는 지역의 실제 그림·지도·장수·수치로 채웁니다.

- 타이틀: 전략 지도 위 네 나라 꼬리표 · 명령 대기: 지역 그림과 병사·금·군량·민심 · 매달 초: 계절 설명과 12달 띠(9월 수확 표시) · 전투: 전장 그림과 양측 병력 막대
- 명령 20개마다 정해진 카드: 이동·수송(지도에 경로 화살표), 전쟁(적 지역으로 붉은 화살표와 병력 비교), 첩보(레이더 원과 동그라미 주석),
  군사·포상·추방(장수 사진과 병력·충성 막대, 추방은 붉은 X), 외교(나라 도장과 우호도 선), 세력(영토 막대 그래프), 상인(달별 곡물값 선 그래프),
  세율(세율 계기판과 민심), 개간·치수·시혜(지역 사진에 주석과 개발·치수·민심 막대), 위임(委任 도장) 등
- 움직임은 등장 한 번(위로 떠오름·형광펜 긋기·선 그리기)과 느린 반복(사진 천천히 당겨 보기, 레이더)뿐입니다. 동작 줄이기 설정에서는 멈춥니다.

### 조작

- 숫자 키로 고른 뒤 Enter. 다른 선택지와 겹치지 않는 번호는 Enter 없이 바로 결정됩니다.
- 지역을 고를 때는 지도를 눌러도 됩니다. Y/N, Esc(취소)를 쓸 수 있고, 버튼으로도 모두 조작할 수 있습니다.
- 저장은 브라우저 localStorage에 5칸까지 할 수 있습니다.

### 경제·전투 규칙 요약

- 1월·7월에 세금(금)을 걷고, 9월에 수확(군량)합니다. 병사는 매달 군량을 먹습니다.
- 여름 홍수(치수가 낮을수록 잦음), 역병, 메뚜기 떼, 풍년, 민란이 일어납니다.
- 패한 장수는 도주하거나 포로가 되고, 포로는 등용·석방·처형할 수 있습니다.

### 전쟁 (원작 『삼국지 2』 방식)

원작을 직접 실행해 관찰한 절차와 화면([docs/01-rtk2-eng-analysis.md §8](docs/01-rtk2-eng-analysis.md))을 따랐습니다.

**출진 준비**: 공격할 지역 → 출진 장수(최대 10명, **처음 고른 장수가 총대장**) → 군량("한 달 분 N석 필요", 병사 1명당 한 달 1석) → 가져갈 금 → 요약을 보고 출진 확인.

**전장**
- 지역마다 고정된 13×15 육각 전장입니다(원작처럼 가로 13칸). 지형은 원작 코드 체계를 따라 평지·초원·숲(林)·산(山, 통행 불가)·강·구릉(丘)·성(城)이고, 성이 2~4개 있으며 그중 하나가 본성입니다.
- 수비측은 본성(총대장)과 다른 성, 그 주변에 배치합니다. 플레이어가 수비측이면 자동 편성과 직접 편성(최대 10명) 중에서 고릅니다. 남은 장수는 예비 병력입니다.
- 공격측은 **출발한 지역 쪽 가장자리의 진입 칸**에 한 부대씩 배치합니다. 진입 칸은 점선으로 표시됩니다.
- 동맹국이 인접해 있으면 원군 한 부대가 합류합니다.
- 전투 패널(원작과 같은 구성): 지명·날짜·**날씨**·**바람**, 양측 군주 초상과 병사·장수(출전/예비)·군량·금.

**하루 진행**: 수비측이 먼저, 공격측이 나중에 움직입니다. 부대마다 원작 메뉴로 명령합니다.

| 명령 | 내용 |
|---|---|
| 1 이동 | **일반 이동**: 이동력 = (훈련−1)÷20+2. 비용은 평지 2, 초원·숲·구릉·성 3, 강 5이고 산은 지날 수 없습니다. **적 밀어내기**(금 10): 붙어 있는 적을 한 칸 밀어냅니다. 적과 맞닿으면 멈춥니다. |
| 2 공격 | **일반** · **동시**(대상에 붙은 아군 전부가 함께 침, 각자 손실이 줄어듦) · **화계** · **돌격**(1~10회 연속 공격, 적이 무너지면 그 칸으로 진입하고, 버티면 밀어냄). 무력 차이가 크면 **일기토 이벤트**가 일어납니다. |
| 3 대기 | 아무것도 하지 않습니다. |
| 4 정보 | 아군·적 장수의 상태를 봅니다. 행동을 소모하지 않습니다. |
| 5 계략 | **이간**(금 100, 충성이 낮은 적 장수를 아군으로) · **일기토** 신청 |
| 6 퇴각 | 부대가 전장을 떠납니다. 총대장이 퇴각하면 그 편이 집니다. |

매일 처음에 직접 지휘, 오늘은 맡김, 끝까지 맡김(AI), 전군 퇴각 중에서 고를 수 있습니다.

**원작 공식** (MAIN.EXE 역공학, [§9](docs/01-rtk2-eng-analysis.md))
- 전투력 = 무력×3 + 장비율(무장) + 훈련
- 한 번 싸우면 양측이 동시에 손실을 입습니다: `(상대 전투력 − 내 전투력 + min(상대 병사, 0~299)) × 10 ÷ 지형계수 ÷ 공격 수`. 0 이하이면 1~30입니다.
- 지형계수: 평지·초원 10, 숲 12, 강 8, 구릉 15, 성 20. 성 안의 부대를 공격하는 쪽은 5(손실 2배)입니다.
- 화계: 지형별 기본 확률(평지 80, 초원 90, 숲 70, 구릉 50, 성 20, 강 0) + 0~9, 양측 지력으로 보정합니다. 비·눈에는 쓸 수 없고 불은 바람을 따라 번집니다.
- 일기토: 체력 = 무력, 최대 10합입니다. 약한 쪽은 무력 차 ÷ 5만큼 타격이 약해집니다. **무력이 더 높은 상대를 이기면 무력이 둘의 평균으로 오릅니다.**
- 군량이 떨어지면 매일 모든 부대가 병사 5~9%를 잃습니다(탈영).

**승패**
- 상대 **총대장**을 쓰러뜨리거나 사로잡으면 이깁니다.
- 공격측이 **본성**에 들어가거나, 상대 부대가 모두 없어지면 끝납니다.
- 30일이 지나면 공격측이 물러납니다.
- 병력을 모두 잃은 장수는 70% 확률로 사로잡힙니다. 이긴 쪽이 포로를 등용·석방·처형하고, 진 쪽이 잡은 포로는 풀려납니다.

  engine/    types, state(생성·조회), economy(월간 처리), hex(헥스 격자·지형·경로), battle(전술 전투·포로),

  ui/        ui.ts(IO 구현·입력), map.ts(SVG 지도), battleMap.ts(SVG 전장), scenes.ts(해설 카드), assets.ts(그림 경로), josa.ts(조사 자동 교정), style.css
  dev/       seed.ts(시드 난수), check.ts(상태 불변식), headless.ts(화면 없는 실행기·몽키 IO), debug.ts(?debug 패널)

tests/          Vitest 테스트

## 알려진 한계

- 원작의 계략(Strategy) 하위 메뉴는 에뮬레이터 입력 문제로 직접 확인하지 못해 화계·이간·일기토로 재구성했습니다. 병종(기병·궁병)은 없습니다.
- 실존 인물만 쓰기 때문에 수십 년이 지나면 장수 수가 줄어듭니다. 가상 모드에서는 수명이 5년 늘어납니다.
- 능력치와 일부 생몰년은 게임용 추정치이며 사료 고증을 거치지 않았습니다.
