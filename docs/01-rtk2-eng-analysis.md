# 삼국지2 영문판 웹 플레이 분석 (sam.paengi.com)

- 분석일: 2026-10-18
- 대상: https://sam.paengi.com/ → "삼국지2 영문판 플레이" (`?game=sam2_eng`로 바로 실행 가능)
- 목적: 한국 삼국시대(신라·백제·고구려 + 당) 버전으로 다시 만들기 위한 기초 자료

> 표기 규칙: **[관찰]** = 사이트·소스맵·실행 화면에서 직접 확인한 사실, **[추정]** = 원작 RTK2에 대한 일반 지식이나 추론(실행 화면에서 끝까지 확인하지 않음)

## 1. 결론 요약

1. 이 사이트는 게임을 새로 만든 것이 아닙니다. **DOSBox(js-dos 6.22, WebAssembly)로 1989년 KOEI의 DOS판 원본 실행 파일을 브라우저에서 그대로 돌리는 래퍼**입니다. [관찰]
2. 래퍼는 Vue 2 + TypeScript + webpack 4로 만들어졌고, **소스맵(`main.js.map`)이 공개되어 있어** 원본 소스(`src/app.vue`, `src/components/game.vue` 등)를 그대로 읽을 수 있습니다. [관찰]
3. 게임 로직(내정·외교·전투·AI)은 전부 `MAIN.EXE`(약 250KB, 16비트 DOS 바이너리) 안에 있습니다. 웹 쪽 코드에는 게임 규칙이 **전혀 없습니다**. [관찰]
4. 따라서 "한국 삼국시대 버전"은 **원본 바이너리를 고쳐 쓰는 방식이 아니라 새로 구현하는 방식(클린룸 재구현)**으로 가는 것을 권장합니다. 이유는 §6에 정리했습니다.

### 2.1 메뉴와 게임 설정 (`src/app.vue`)

모든 게임은 `onStartGame(mod, entry, saveFiles)` 하나로 시작합니다.

| 메뉴 | mod | entry | 세이브 파일 |
|---|---|---|---|
| 삼국지2 한글판 | `sam2_kor` | `KOEI.BAT` | `1`~`5` |
| **삼국지2 영문판** | **`sam2_eng`** | **`KOEI.BAT`** | **`1`~`5`** |
| 삼국지3 | `sam3` | `KOEI.COM` | `SANGOKU3.SAV`, `NBDATA.DAT` |
| 삼국지4pk | `sam4pk` | `sam4.bat` | `SAVEDAT.S4`, `NBDATA.S4` |
| 영걸전 | `hero` | `hero.com` | `MSAVE0~4.R3S`, `ESAVE0~4.R3S` |
| 수호전 | `suho` | `koei.com` | `SAVEDATA` |
| 징기스칸3 | `khan3` | `koei.com` | `SAVEDATA.GK2` |

`?game=<mod>` 쿼리를 붙이면 메뉴를 건너뛰고 "단일 게임 모드"(툴바 숨김)로 바로 실행됩니다.

### 2.2 실행 순서 (`src/components/game.vue` `mounted()`)

```
1. document의 keydown/keyup/keypress addEventListener를 가로챔 (event.ts)
2. IndexedDB 열기: DB 이름 = mod ("sam2_eng"), store = "files"
3. js-dos 생성 → fs.extract("static/sam2_eng.zip")
4. IndexedDB에 저장된 세이브 파일(1~5)을 DOS 가상 파일시스템에 기록
5. main(["-c", "KOEI.BAT"]) 로 DOSBox 시작
6. 가로챈 키 핸들러를 보관 → 원래 addEventListener 복원
7. 300ms마다 세이브 파일 mtime을 확인 → 바뀌면 350ms debounce 후 IndexedDB에 저장
   + "세이브 파일이 브라우저에 저장되었습니다" 토스트
```

### 2.3 세이브 시스템

- 게임 안에서 "1"~"5"라는 파일 이름으로 저장해야 브라우저에 보존됩니다(첫 화면 안내문과 일치). 다른 이름으로 저장하면 감시 대상이 아니라서 새로고침하면 사라집니다.
- 툴바의 저장/불러오기 버튼은 IndexedDB ↔ 로컬 파일(Blob 다운로드 / file-dialog 업로드)을 오갑니다.
- `beforeunload`에서 "저장하지 않은 내용이 날아갈 수 있습니다" 경고를 띄웁니다. 방금 저장했으면 5초 동안 경고를 띄우지 않습니다.

### 2.4 입력 시스템

- 화면 오른쪽 가상 키패드는 텐키 배열(7↖ 8↑ 9↗ / 4← 5 6→ / 1↙ 2↓ 3↘ / 0=Y, Enter=N, Space, ESC, Back)입니다.
- 키를 누르면 `KeyboardEvent`를 직접 만들어(`keyCode`만 덮어씀) 가로채 둔 DOSBox 핸들러에 바로 넘깁니다.
- 대각선은 Numpad 1/3/7/9 keyCode로 보냅니다. 육각형 전투 맵의 6방향 이동에 쓰입니다.
- 삼국지4pk·영걸전은 마우스 모드가 기본이고, 터치 D-pad로 가상 커서를 움직입니다.
- 화면 비율은 640×480(4:3) 고정이고, 가로/세로 모드별로 키패드 크기를 다시 계산합니다.

## 6. 재구현 권장 방향

### 6.1 원본 바이너리를 고쳐 쓰지 말아야 하는 이유

1. **저작권:** `MAIN.EXE`, 그래픽(`KAODATA` 등), 시나리오 데이터는 KOEI(현 코에이테크모)의 저작물입니다. 이것을 고쳐서 배포하면 2차적 저작물이 되어 법적 위험이 있습니다.
2. **기술적 한계:** 지도는 41개 주 비트맵에 고정되어 있고, 영문판 폰트는 ASCII 전용입니다(한글판은 별도 빌드). 지역 수·지도 형태·세력 수를 바꾸려면 16비트 실행 파일을 깊게 패치해야 합니다.

### 6.2 권장 구조: 웹 네이티브 재구현

래퍼에서 가져올 만한 것(아이디어만 참고하고 코드는 새로 작성):
- 640×480 고정 비율 캔버스와 오른쪽 가상 텐키 패드(모바일 대응)
- IndexedDB 슬롯 세이브(1~5), 세이브 파일 내보내기/가져오기

### 8.2 전장 [관찰]

- 화면을 넘는 큰 육각 전장이다(스크롤). 지형은 평지·숲·산·강(넓은 물길)이고, **성(城) 칸이 여러 개** 흩어져 있다.

- 1일째는 수비측(동탁군)이 먼저 움직였다("Fan Chou's tactics … ‹wait›").
- **일기토는 이벤트로 일어난다**: "I, Lu Bu, challenge you to combat!" → 하후연이 응함.

### 8.3 확인하지 못한 것 [추정]

### 9.3 전투 공식 [코드]

**부대 전투력** `3333:03d2`

```
전투력 = 무력 × 3 + 장비율 + 훈련      (특정 번호 0xA3 장수는 무력 +20)
장비율 = min(100, 무기 × 100 / 병사)    `1525:00ee`
```

**손실 계산** `34aa:01b8` → `3333:042a`: 공격 한 번에 **양측이 동시에** 손실을 입는다.

```
X의 손실 = (상대 전투력 − X 전투력 + min(상대 병사, 난수 0~299)) × 10 ÷ 지형계수[X가 선 칸] ÷ 공격 부대 수
          (결과가 0 이하이면 1~30의 난수)
```

- 동시공격: 공격 부대 수로 나눈다.
- 플레이어 부대를 AI가 공격하면 AI 쪽 손실을 `÷ (공격 수 + 난이도 − 1)` 로 줄인다.
- 손실이 남은 병사보다 크면 그 부대는 괴멸한다. 양측 모두 괴멸할 수도 있다(`34aa:0140`).
- 무기 수도 같은 비율로 줄어든다.
- **성 안의 부대를 공격하는 쪽**은 지형계수 7번(=5)을 써서 **손실이 두 배**다. 조건은 손실을 주는 쪽(=공격 대상 `0xb8e4`)이 성 칸에 있을 때이고, 성 안의 수비측은 계수 20으로 손실이 절반이다.

**지형 표** (지형 코드 0~7, 데이터 세그먼트 0xb36e·0xb376·0xb6cc·0xc304)

| 코드 | 지형 [추정] | 화계 기본 확률 | 방어 지형계수 | 이동 비용 |
|---|---|---|---|---|
| 0 | 평지 | 80 | 10 | 2 |
| 1 | 초원 | 90 | 10 | 3 |
| 2 | 숲 | 70 | 12 | 3 |
| 3 | 산 | 60 | 10 | **통행 불가**(플레이어) / 7(AI) |
| 4 | 강·물 | **0** | **8** | **5** |
| 5 | 구릉 | 50 | 15 | 3 |
| 6 | 성 | 20 | **20** | 3 |
| 7 | (성 공격 시 공격측) | – | 5 | – |

**이동력** `3475:031e`: 매일 `max(남은 이동력, (훈련−1)/20 + 2)` 로 회복한다. 훈련 10이면 2(평지 1칸), 훈련 100이면 6이다.

**공격 종류** `35fd:09b0` "Which attack? (1-4)" [코드]

| 번호 | 종류 | 동작 |
|---|---|---|
| 1 | Normal | 1:1 공격 `35fd:0246` |
| 2 | Simultaneous | 대상에 붙은 아군 부대 전부(6방향)가 함께 공격, 공격 수로 손실을 나눔 `35fd:00a2` |
| 3 | Fireball | 화계 `35fd:0834` / `34aa:008c` |
| 4 | Charge | **난수 1~10회 연속 공격**. 적이 무너지면 그 칸으로 전진하고 적을 밀어냄 `35fd:0348`. (100−지력)% 확률로 특수 플래그 [추정: 장수 위험] |

**화계 성공률** `34aa:008c`, `3333:035a`

```
기본 = 지형별 화계 확률 + 난수 0~9            (물은 0, 날씨 코드 3이면 불가 [추정: 비])
적 부대가 있으면: 확률 = min(100, (101 − 적 지력) × 기본 / 100 + 난수(max(0, 내 지력 − 적 지력)) / 2)
```

결과 메시지: It worked! / Oops! (아군 쪽) · Caught fire! / Fireball failed (적 쪽). 불 붙은 칸에는 플래그 0x20이 서고 그 칸 부대가 피해를 입는다 `377e:0396`.

**이동 메뉴** "1.Normal move 2.Move enemy". 적 밀어내기는 **금 10**을 쓴다("Not enough gold", `3984:083a`).

**일기토** `3878:0c2a`, `3878:0b84`, `3878:0d56`

- 체력은 무력에서 시작하고, **최대 10합**이다("Round %2d").
- 각 합마다 양측이 난수 피해를 준다. 무력이 높은 쪽은 0~19, 낮은 쪽은 상한이 (무력 차 ÷ 5)만큼 줄어든다.
- 체력이 0이 되면 진다. 10합이 지나면 "Stalemate!"다.
- **무력이 더 높은 상대를 이기면 무력이 둘의 평균으로 오른다** ("war ability increased from %d to %d").
- 거절 메시지 "is a coward!" / "refuses to fight!". 부하가 일기토를 진언하기도 한다("suggest personal combat").
